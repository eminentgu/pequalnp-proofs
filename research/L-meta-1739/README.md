# Lower bounds toward L-meta-1739

The posted goal concerns every cyclic graph without a four-cycle and requires at least |E| + τ − 1 gates to detect an edge. The general case remains open here.

* **LeafCharge.lean** proves a gate elimination result for fan-in-two monotone circuits. Fix a sensitive input high (and optionally another input low). If the restricted function still has a false assignment, constant propagation saves at least one AND. The proof tracks the first place where a sensitive wire ceases to be forced true. It reuses the certified constant propagator from upstream L-meta-1737.
* **CyclicBounds.lean** fixes a leaf high and its unique neighbour low. The resulting circuit computes the edge function with all edges incident to that neighbour deleted and uses strictly fewer ANDs. This proves the vertex-cover lower bound on ANDs whenever repeated leaf steps reach a graph admitting a cover of size at most five. The starting graph can have arbitrarily large cover number. The terminal AND bound comes from upstream L-meta-217. Together with the OR bound from L-meta-4837, this proves the posted inequality on all four-cycle-free pseudoforests admitting such a sequence.
* **OrderedMatching.lean** proves that an ordered matching of size k forces at least k AND gates in any monotone edge detector. Its left endpoints must be independent, and an earlier left endpoint cannot be adjacent to a later right endpoint. There is no four-cycle hypothesis. Enable the left endpoints in order. At each step the matching edge supplies a sensitive pair and the independent set supplies a rejecting assignment.
* **Certificate.lean** combines the AND bounds with OR certificates. A four-cycle-free induced pseudoforest supplies its full edge count toward the number of ORs plus one. Each previously deleted active vertex adds one to that bound if an edge survived its deletion. An OR certificate reaching |E| and an AND bound reaching τ imply the exact inequality requested by the desk.

**Exact gate counts.** ExactSize.lean combines these lower bounds with the upstream cover constructions L-meta-214 and L-meta-5355. If an ordered matching meets an equally small cover, its size is the exact AND complexity, even without sparsity or a four-cycle restriction. For a four-cycle-free pseudoforest satisfying the same matching condition, the optimum total size is |E| + k − 1. The file instantiates the latter theorem on the six-cycle with one private leaf at each cycle vertex. Its 12 edges, six matching pairs, six-vertex cover and exact optimum of 17 gates are checked in Lean.

**Counterexample search.** Run `uv run --no-project --with networkx==3.6.1 python atlas_search.py`. The search takes every connected, four-cycle-free graph with more edges than vertices in the NetworkX atlas through seven vertices. On the 27 resulting graphs it constructs circuits from every minimum vertex cover, every admissible edge assignment, and two fixed folding orders. From each of the 812 distinct starting circuits it bypasses each gate to each earlier wire, optionally replacing another surviving gate by any AND or OR of two earlier wires. All truth tables cover the full input space. No shorter circuit was found in these neighborhoods. Other circuit shapes remain possible.

To replay using the repository’s pinned Lean and Mathlib, first build PEqualNP.Outside.L_meta_1737, PEqualNP.Outside.L_meta_217 PEqualNP.Outside.L_meta_4837, PEqualNP.Outside.L_meta_214 and PEqualNP.Outside.L_meta_5355 with Lake. In the resulting Lean environment add this research directory to LEAN_PATH, then compile LeafCharge.lean, CyclicBounds.lean, OrderedMatching.lean, Certificate.lean and ExactSize.lean in that order, using lean -o to write each matching .olean. These research modules use checked upstream proof modules beyond the imports allowed for a desk submission.
